# http-image-switcher

Учебный проект для обмена командами между двумя ноутбуками в одной локальной сети. На первом ноутбуке кнопка отправляет HTTP-запрос, а на втором в окне меняется изображение.

## Установка

На обоих ноутбуках в папке проекта:

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

На Linux/macOS вместо второй строки: `source venv/bin/activate`.

Картинки (`.png` или `.jpg`) положить в папку `images` на ноутбуке с receiver.

## Запуск

На втором ноутбуке (с картинками):

```
python receiver/receiver.py
```

На первом ноутбуке, указав IP второго:

```
python sender/sender.py 192.168.1.42
```

Без IP sender подключается к `127.0.0.1`, так можно проверить всё на одном ноутбуке.

## Как узнать IP

На ноутбуке с receiver:

- Windows: `ipconfig`, строка "IPv4-адрес" у Wi-Fi адаптера;
- Linux/macOS: `ip a` (или `ifconfig`), адрес вида `192.168.x.x` у `wlan0`/`en0`.

## Если не подключается

- оба ноутбука должны быть в одной сети (одна Wi-Fi точка, без гостевой сети и VPN);
- брандмауэр на ноутбуке с receiver должен пропускать порт 8000: в Windows при первом запуске разрешить доступ для Python в частных сетях, или открыть порт вручную;
- проверить, что receiver запущен: открыть в браузере на первом ноутбуке `http://IP:8000/next`, должно показать `ok`;
- если sender пишет "receiver not available", значит запрос не дошёл, проверить IP.

## Как работает

```
sender --HTTP GET /next--> receiver --> следующая картинка
```

receiver запускает HTTP-сервер на порту 8000 в отдельном потоке, а в главном потоке рисует окно pygame. При запросе `/next` сервер увеличивает номер текущей картинки, и окно на следующем кадре показывает новую. sender при нажатии на кнопку "Next" отправляет этот запрос через `requests`.
